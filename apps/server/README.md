# Server

The Otter Scaffold environment server: a Node WebSocket server that owns the app's data, runs the
agent, and serves the web client. It ships as the `otter-scaffold` command (`t3` inside the
repository) and inside the desktop app.

See the [architecture overview](../../docs/internals/overview.md) and
[the agent](../../docs/internals/agent.md) for how it is put together, and the
[development runbook](../../docs/operations/development.md) to run it.
