# Open source licenses

Otter Scaffold includes third-party software and assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → Open source licenses**, or **View licenses** under
  **About** in **Settings → General**.
- On mobile, open **Settings → About Otter Scaffold → Open source licenses**.

The list shows each item's version when available, its license, and the parts of the app that use
it. Select a row to read the full notice, or search by package, version, or license.
